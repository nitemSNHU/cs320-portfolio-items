# cs320-portfolio-items
A collection of items I created in CS320 for Software Testing and Automation
-   **How can I ensure that my code, program, or software is functional and secure?**
- To ensure that code is functional and secure, steps should be taken both during development and testing. For the focus of this course, I will look at testing. Using a good testbench is important as it ensures your code will function in a variety of scenarios and won't find itself in unpredictable runtime errors that aren't handled. To do this, a testbench needs to use proper testing techniques, and get good coverage of the code. To get good coverage of code, you should check many random normal functioning cases and several edge cases where you want to ensure behavior is well-defined.
-   **How do I interpret user needs and incorporate them into a program?**
- User needs can be difficult to interpret, as people's stated preferences don't always align with their revealed preferences. Nevertheless, the first pillar is basic things any user would want: security and the program functioning with its core features as intended. You can further find user needs by conducting market research, making user stories, conducting interviews with focus groups, etc. This may also be needed to approach during testing as users may have needs that a testbench should take into consideration. For instance, a famous failure of this is last name checks where people have two-letter last names like Xi or Wu. While a tester can verify that last names are bounded within a certain range, diverse human experiences are needed to know what issues consumers may face even if the program properly enforces boundaries.
-   **How do I approach designing software?**
- Designing software starts by defining user needs as interpreted, implemented with code design, and fortified with proper testing, both of functional requirements and security requirements, throughout the coding process. It should be done within a structured Software Development Life Cycle where testing is continuously integrated throughout the design. This can be done by integration tests, regression tests, and various black and white-box testing techniques to ensure design quickly matches to function.
